# Map boundary

Source: existing README/code and the requested prevention of falling off the map. Size S. Use the existing WalkableValleyTerrain mesh bounds, with a two-metre inset (at least the player's radius) for the rectangular farm. Keyboard and touch continue through PlayerMovement; no new dependencies, editor scene rewrites, inventory loss or save changes.

Constrain each proposed horizontal movement to that inset. Track a ground-supported safe position inside the region. If the player falls more than three metres below the terrain surface, or below the mesh's lowest point minus ten metres when there is no hit, teleport to the last safe point (or a projected interior point if none was recorded). Reset falling velocity, stop movement and cancel fishing on recovery. Maps without this terrain retain existing movement.

Alternatives considered: invisible perimeter colliders (extra scene geometry and editing); hard-coded coordinates (would drift when map changes). Reuse runtime mesh bounds because the current map is a rectangular 200 m terrain. No swimming, river barriers or NPC boundary redesign.
