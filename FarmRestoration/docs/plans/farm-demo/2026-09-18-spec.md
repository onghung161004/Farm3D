# Farm Restoration: First Playable Vertical Slice

## Goal

Create a compact 3D low-poly farming demo for Android and Windows. A player can move around a small farm, use a selected tool on one soil plot, plant a seed, water it, advance the crop through visible stages, and harvest it into an inventory counter.

## Player experience

The player arrives at a neglected plot of land. Using a simple third-person camera, they move to the plot and press a contextual interact button. The plot visibly changes from grass to tilled soil, then seeded, watered, growing, and harvest-ready. Harvesting increments the crop counter in the HUD and resets the plot for a new loop.

## Scope

- Unity 6.6 URP project with Input System.
- `FarmDemo` scene with low-poly primitive placeholder environment and directional lighting.
- Keyboard controls for Windows Editor; touch controls are deliberately deferred but the input architecture must be ready to extend.
- Third-person player movement, follow camera, interaction ray/trigger, one farm plot, crop state machine, tool selection, basic HUD, and particle/audio extension points.
- Android build profile settings and a repeatable smoke-test checklist.

## Non-goals

- Multiple crop types, saving/loading, NPCs, animals, shops, quests, weather, multiplayer, procedural terrain, final art assets, or production touch UI.
- Downloading third-party assets or changing Unity packages except Cinemachine if needed for the camera implementation.

## Quality constraints

- Target 60 FPS on a mid-range Android device and no per-frame allocations in player, plot, or HUD update loops.
- Keep the first scene below 100 active objects and use only URP-compatible materials.
- Gameplay must also run with keyboard in the Unity Editor for fast assessment.

## Acceptance demo

1. Launch `FarmDemo` from the Unity Editor.
2. Move the player with WASD/arrow keys; camera follows smoothly.
3. Select hoe, seed, water can, then harvest in the displayed sequence.
4. Interact while in range of the plot to progress only through valid states.
5. Harvest increments the HUD crop count and resets the plot.
