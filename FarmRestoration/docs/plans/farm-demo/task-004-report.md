## State flow

`Untilled --Hoe--> Tilled --Seeds--> Seeded --WateringCan--> Watered --AdvanceGrowth--> Growing --AdvanceGrowth--> ReadyToHarvest --Harvest--> Untilled`

Every other tool/state pair returns `false` without changing state or visual. Harvest only raises `Harvested(1)` after a valid harvest; the immediate second harvest returns `false`.

## Safe scene setup

1. Open `Assets/FarmRestoration/Scenes/FarmDemo.unity`.
2. Run `Tools > Farm Restoration > Create Farm Plot Prefab (If Missing)` once. This creates `Assets/FarmRestoration/Prefabs/FarmPlot.prefab` without changing the scene.
3. Run `Tools > Farm Restoration > Add Farm Plot To Current Scene` only when the active scene has no plot; this instantiates the reusable prefab and is undoable with `Ctrl+Z`.
4. Save with `Ctrl+S`.

The scene command searches only the active scene, including inactive objects. If it finds a plot there, it selects it and leaves the scene unchanged; plots in other loaded scenes cannot block setup. It never overwrites or deletes `FarmDemo`.
